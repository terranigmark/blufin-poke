# Project instructions

Follow `uploads/SKILL.md` (AI Design Process: Discover → Define → Deliver) for all design work in this project.

- Brand direction is already fixed by the user's reference images (navy #10304D, cream #F2EADB, Bebas Neue / Barlow / Kaushan Script), so Discover-stage exploration applies only to new sections or when asked.
- Define: judge work from screenshots, compared against a named aesthetic and how a top studio would execute it; cap critique loops at 1–2 rounds.
- Deliver: polish subtractively. Check for eyebrow labels, decorative gradients, excess cards/containers, too many text styles, and performative copy. Propose cuts to the user before large removals.
- Prefer real photography over CSS effects.
